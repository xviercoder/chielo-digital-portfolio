OVERVIEW

Project concept

UNESA Preloved is a static frontend prototype for a preloved marketplace concept intended for UNESA students. Its design uses a navy, gold, and warm-cream visual direction. The landing page communicates a concept of turning unused items into value, while the marketplace interface supports product discovery through search and category filters.

IMPLEMENTED

What is included in the prototype

  • Landing page with product-to-value narrative and navigation.
  • Login/register interface with a demo front-end check for the @mhs.unesa.ac.id email domain.
  • Marketplace page with product cards, keyword search, and category filtering.
  • Product detail page.
  • Sell-item form with image preview and a live listing summary preview.
  • Separate cart, checkout, and profile HTML screens are included in the demo package.

The login/register check is client-side only. The demo stores an email in sessionStorage and redirects to the marketplace; it does not authenticate a real user.

LIMITATIONS

What is not implemented yet

Frontend prototype only — no production backend

The supplied README describes Supabase Auth, Supabase database/RLS, and Cloudinary as planned production integration steps. These are not implemented in the supplied frontend package.

  • No real account authentication or authorization.
  • No persistent product listing or transaction storage.
  • No live messaging, payment, or order processing backend.
  • The sell form displays a prototype alert instead of submitting to a backend.
  • Some controls such as favorites, chat, negotiation, sorting, and pagination are visual or not yet wired to a complete workflow.

Product imagery in the supplied pages references remote Unsplash image URLs, so those images require an internet connection when the demo is opened.
